# 党课题库练习中心

一个**纯静态前端驱动**的党课题库刷题与模拟考试应用，开箱即用，无需后端服务器或数据库。内置 **1,594 道**已完成校核与 AI 解析的题目，针对**手机端单手操作**及**各类折叠屏设备**进行了深度适配。

---

## ✨ 核心功能

### 1. 日常练习（`index.html`）
- **多维检索与定位**：支持按题型筛选（单选 / 多选 / 判断 / 填空）、题干与选项关键词检索，以及按当前序号或题目 ID（如 `Q00025`）精准跳转。
- **高效刷题模式**：
  - 支持**顺序练习**与**随机练习**切换；
  - 单选/判断题点击选项即时判题，答对后停留 **1 秒**自动跳下一题（支持开关控制）；
  - 填空题支持点击题干内「点击看答案」胶带遮罩原地翻开答案；
  - PC 端支持全键盘快捷键：`A–F` / `1–6` 选选项、`←` / `→` 切题、`Space` 显隐答案、`Enter` 提交多选、`S` 标记错题。
- **错题本与本地存档**：答错自动收录进错题本，支持专项「错题复习」与手动标记/移除；所有练习进度与错题均自动保存在浏览器 `localStorage` 中，并支持一键**导出 / 导入 JSON** 跨设备迁移。

### 2. 模拟考场（`exam.html`）
- **智能抽题组卷**：按题型比例随机抽取 **100 题**（单选题 40、多选题 20、判断题 20、填空题 20）。
- **1–100 题可视化答题卡**：实时区分未答 / 已答 / 当前题 / 答对 / 答错状态，点击任意题号直接跳转。
- **交卷复盘与历史记录**：交卷后自动判分、将错题同步至错题本，支持按「全部 / 只看答对 / 只看答错」筛选解析；自动保留最近 20 次历史试卷记录并支持备份导出。

### 3. 移动端与全场景折叠屏深度适配
- **手机端首屏直达题目**：收起冗长侧边栏为底部上滑抽屉（Drawer），配合顶部快捷条与底部固定拇指翻页栏，单手轻松操作。
- **折叠屏专业逻辑**：
  - **四档响应式断点**：兼容超窄外屏（`≤ 390px`）、标准手机/小折叠（`≤ 720px`）、大折叠展开态/平板双栏（`721–1120px`）以及超矮悬停屏（`max-height: 540px`）；
  - **物理折痕避让（Viewport Segments API）**：在左右书本对折与上下悬停姿态下自动避开中间铰链折痕；
  - **物理半折悬停（Device Posture API）**：半折放置桌面时，上半屏专注展示题干、下半屏集中放置触控操作；
  - **触屏大屏识别（`@media (pointer: coarse)`）**：即使三折叠展开至桌面宽度，仍保持大触控热区并隐藏无用的键盘提示；
  - **展开态智能排版与手势**：短选项自动切换 **2×2 双列网格**；支持答题卡区域**左右轻滑手势切题**；折叠/展开瞬间自动收起抽屉遮罩并锚定当前题目防丢失。

## 🚀 使用与部署

### 本地直接使用
直接在现代浏览器（Chrome / Edge / Safari / 手机浏览器）中打开 `index.html` 即可开始练习；也可在本地目录启动静态服务供局域网手机访问：
```powershell
python -m http.server 8080
```

### 部署到 GitHub Pages（推荐）
本项目前端无需任何服务端，仅需将以下 **7 个纯静态文件**上传至 GitHub 仓库并在 `Settings -> Pages` 中选择 `main` 分支根目录即可完成免费公网部署：
- `index.html`、`exam.html`、`app.js`、`exam.js`、`styles.css`、`questions.js`、`questions.json`

> **注意**：部署静态站点时无需上传 `.venv/` 和 `.py` 维护脚本。

## 🛠️ 离线题库维护工具（可选）

维护脚本均使用项目根目录下的 `.venv` 运行（已预装 `python-docx`、`pymupdf`、`rapidocr_onnxruntime`、`openai`）：

1. **从 Word / PDF（含扫描版 OCR）提取并去重合并到题库**：
   ```powershell
   .\.venv\Scripts\python.exe extract_and_merge.py "新题库.pdf" "补充.docx" --target-json questions.json
   ```
   > 仅预览提取与去重统计可加 `--dry-run`；PDF 乱码强制全量 OCR 可加 `--force-ocr`。

2. **使用 DeepSeek-V4.1-Flash (`deepseek-flash`) 并发补全解析**：
   ```powershell
   $env:DEEPSEEK_API_KEY = "您的_API_Key"
   .\.venv\Scripts\python.exe fetch_explanations.py
   ```

3. **校准解析与标准答案一致性**：
   ```powershell
   .\.venv\Scripts\python.exe calibrate.py
   ```
